# JalDrishti - "Ghost Crop" Residue & Microplastic Tracer
## Smart India Hackathon (SIH) Solution (Clean & Green + Agriculture Track)

This repository contains the complete production-ready **JalDrishti Web Portal** (`index.html`) featuring a light-themed eco-tech UI, realistic 3D drum scanner & water wave simulation, multi-spectral AI classifier, canal basin GIS mapping, and policy open data feeds.

### Option 1: Publish to Vercel (Free & Instant)
Run the following command in your terminal:
```bash
npx vercel --prod
```

### Option 2: Publish to Netlify (Free & Instant)
Run the following command in your terminal:
```bash
npx netlify-cli deploy --prod --dir=.
```

### Option 3: Publish to GitHub Pages
1. Push this `SIH` directory to a GitHub repository.
2. Go to **Repository Settings** -> **Pages** -> Select **Main Branch** -> Click **Save**.
3. Your site will be published at `https://<username>.github.io/<repo-name>/`.

## 🌟 Key Features Summary

1. **Clean Light Theme**: Modern frosted glassmorphism on a luminous light background with high-contrast typography and aquatic emerald/cyan accents.
2. **Realistic 3D Water & Drum Scanner (`js/vessel3d.js`)**: Dynamic Gerstner wave surface, compact buoyant drum pod with outriggers & solar lid, glowing optical multi-laser fan, and drifting microplastics & stubble ash particles.
3. **Canal Truth Insights (`#canal-truth`)**: Detailed revelations uncovering invisible degraded plastic mulch, precision satellite source attribution, agricultural soil aeration loss, and municipal drinking water protection.
4. **Multi-Spectral AI Simulator (`js/simulator.js`)**: Real-time optical absorbance curves across 380nm-940nm classifying LDPE mulch, stubble ash PAHs, and pesticide runoff.
5. **Canal Basin GIS Map (`js/map.js`)**: Leaflet map in clean light mode featuring monitoring nodes and Sentinel-2 satellite fire hotspot overlays.
6. **Interactive 8-Slide Pitch Deck (`js/ppt.js`)**: Full-screen presentation slide deck with keyboard control for jury evaluation.
